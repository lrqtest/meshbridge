它是什么

一台自建服务器，替你管好设备组网与传输

家里 NAS 要把 200 GB 素材发给海外的工作站；公司服务器要把数据集同步到云上——网盘又慢又限速还不放心。MeshBridge 在你自己的 VPS 上搭一个轻量控制面，把你的设备组成一张私有网络，传输永远走设备之间。

私有 Mesh 组网

基于 Headscale + Tailscale 的自建控制面：设备装上 Agent 自动入网，拿到的 100.x 地址只在你的网络里可见。准入、密钥、拓扑全部由你掌控。

WireGuard 加密 · 无第三方

大文件可靠传输

文件按 64 MiB 分块、逐块 BLAKE3 校验、位图断点续传——传一半断网，重连后从断点继续，不用重来。整体哈希验证通过才算完成。

GB～TB 级 · 可恢复 · 可验证

智能路由选择

持续探测设备间路径：能直连就走直连；被网络环境限制时自动切换你部署的中继节点或对象存储兜底。降级需连续多次采样确认，防止抖动误判。

DIRECT → RELAY → S3 · 自动降级
核心原则

为什么敢说"数据不过手"

MeshBridge 的第一条架构铁律：控制面只做协调（信令、密钥、任务调度），流量只有 KB 级。你的文件永远走设备之间的通道，大文件想蹭 DERP 小水管会被调度器直接拒绝。

三步上手

从注册到传输，十分钟内

1

注册账号

邮箱验证码注册，全程网页操作。首次部署会引导你配置邮件服务，之后可邀请团队按项目隔离设备。

2

接入设备
